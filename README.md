✈ Aircraft Detection System
🚀 Project Overview

This project is an AI-powered Aircraft Detection System built using Deep Learning (YOLOv8) and Streamlit.
It detects aircraft from images and videos and classifies them into different aircraft types.

🧠 Features
✈ Real-time Aircraft Detection
🖼 Image-based Aircraft Classification
🎥 Video Aircraft Detection
🛰 AI-powered radar-style UI
📊 Live detection statistics
🎯 Aircraft type prediction (Boeing & Airbus models)
🌌 Modern futuristic UI with CSS effects
🛠 Technologies Used
Python
Streamlit
OpenCV
YOLOv8 (Ultralytics)
TensorFlow / Keras
NumPy
Pillow
